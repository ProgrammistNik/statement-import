# Statement Import

Нативное приложение для проверки регулярных расходов по синтетической выписке. Главная задача интерфейса состоит в том, чтобы понятно показывать ход импорта и подтвержденный результат.

Характер: спокойный, точный, понятный. Визуальное направление: ясность, порядок, уверенность.

Шрифт Manrope. Основной текст 16, подписи 13, заголовки 25 и 32, итоговая сумма 44. Шрифт поддерживает системное увеличение. Основной шаг отступов 8. Радиусы 12 и 16. Тени не используются, поверхности отделяются тонкой границей.

Фон светлый холодный, текст темно-синий, основная кнопка синяя, акцент светло-зеленый. Статусы подписаны словами. Успех зеленый, ожидание охристое, ошибка темно-красная. Цвета задаются общими токенами приложения.

Основной прием: крупная сумма расходов и отдельная шкала из трех этапов импорта. В каждом состоянии есть одно основное действие. Дополнительная диагностика вынесена на отдельный экран.

Ориентир по структуре: нативные финансовые приложения с простыми списками операций и отдельной карточкой платежа. Системный выбор файла сохраняет привычное поведение платформы.
